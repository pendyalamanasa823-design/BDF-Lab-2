# Lab 02 - Backend Development Fundamentals

This project contains a simple Express + SQLite book API.

## Structure
- `app.js`: Express server entry point
- `app.http`: HTTP requests for testing the API
- `database/`: SQLite database created by the application
- `seed.js` and `seed.sql`: sample book data
- `screenshots/`: API screenshots

## Run
```bash
npm install
npm start
```
